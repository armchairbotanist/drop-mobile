Set up once

  1. Open this page in Safari on your iPhone and download the shortcut.
  2. Open the downloaded Add to Drop.shortcut file from Safari’s downloads or the Files app. In Shortcuts, choose Set Up Shortcut / Add Shortcut.
  3. Paste the same fine-grained GitHub token you use for Drop. It must allow only armchairbotanist/drop-library, with Contents: read and write.
  4. If setup does not ask for the token, open the shortcut’s editor (•••) and paste it into the first Text action beneath the introductory comment.
Keep your configured shortcut private. Its Text action stores the token; this is not Apple Keychain. It may sync with your Shortcuts through iCloud. The downloaded template contains no token. Share this installation page, not your configured copy.

Send a file

  1. In Files, long-press a file → Share → Add to Drop. You can also share multiple selected files, photos, PDFs, or recordings.
  2. On the first run, allow the shortcut to access the selected files and connect to api.github.com.
  3. Keep the Share Sheet open until you see Added to Pantry with the saved filenames. That confirmation appears only after GitHub confirms the files were saved.

If Add to Drop is not listed, scroll through the Share Sheet’s actions. In the shortcut’s Details, check that Show in Share Sheet is on.

What to expect

  • Files go straight to Pantry. Open Drop and sync to see them on another device.
  • Names use lowercase. A same-name file gets a timestamp suffix; existing files are never overwritten.
  • Uploads run one at a time. Internet access is required; this shortcut does not queue offline uploads.
  • Up to 100 MiB per file, subject to the iPhone’s available memory. Start with a small PDF or text file.
  • Your original files stay where they are. If a run is interrupted, check Pantry before retrying—some files may already be saved.
  • Share the actual file. Folders and webpage links are not supported. If Safari or Canvas shares only a link, download the file first or use Add a link inside Drop.

If it fails

No Added to Pantry message means the upload has not been fully confirmed. GitHub errors show any files already saved in that run. A connection interruption may instead show Apple’s own error. Check Pantry, then retry only the missing files.

For a revoked or expired token, replace the first Text action in the shortcut. Do not clear Drop’s website data or reconnect its Library to repair this separate shortcut.

This shortcut uses Apple’s built-in actions and talks directly to GitHub. It does not upload your files or token to this public website.
