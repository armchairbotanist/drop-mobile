Add to Drop

Share a file from your iPhone straight to Pantry.

Download Add to Drop

Shortcut v1.4 · one file at a time · no extra app or subscription

Choose Replace if prompted, then enter your token once for the new copy. After testing, remove the old Single File Test shortcut to avoid duplicate Share Sheet entries. The first comment in the new editor says v1.4.

Set up once

  1. Open this page in Safari on your iPhone and download the shortcut.
  2. Open the downloaded Add to Drop.shortcut file from Safari’s downloads or the Files app. In Shortcuts, choose Set Up Shortcut / Add Shortcut.
  3. Paste the same fine-grained GitHub token you use for Drop. It must allow only armchairbotanist/drop-library, with Contents: read and write.
  4. If setup does not ask for the token, open the shortcut’s editor (•••) and paste it into the blank Text action named Token.
Keep your configured shortcut private. Its Text action stores the token; this is not Apple Keychain. It may sync with your Shortcuts through iCloud. The downloaded template contains no token. Share this installation page, not your configured copy.

Send a file

  1. In Files, long-press one file → Share → Add to Drop.
  2. On the first run, allow the shortcut to access the selected files and connect to api.github.com.
  3. You’ll see an Uploading… banner. Keep the Share Sheet open until Added to Pantry appears with the filename—only after GitHub confirms it was saved. Neither banner needs an OK tap.

If Add to Drop is not listed, scroll through the Share Sheet’s actions. In the shortcut’s Details, check that Show in Share Sheet is on.

What to expect

  • Files go straight to Pantry. Open Drop and sync to see them on another device.
  • Names use lowercase, with spaces converted to hyphens and four random digits before the extension: insurance-4821.pdf. Existing files are never overwritten.
  • Share one file per run. Internet access is required; there is no offline queue.
  • Start with a small PDF or text file. Large uploads also depend on your iPhone’s available memory.
  • Your original file stays where it is. If a run is interrupted, check Pantry before retrying—it may already be saved.
  • Share the actual file. Folders and webpage links are not supported. If Safari or Canvas shares only a link, download the file first or use Add a link inside Drop.

If it fails

No Added to Pantry message means the upload has not been confirmed. A connection interruption may show Apple’s own error. Check Pantry before retrying. If the same name and four-digit suffix happen to exist, the upload fails safely; another run picks a new number.

For a revoked or expired token, replace the Token Text action in the shortcut. Do not clear Drop’s website data or reconnect its Library to repair this separate shortcut.

This shortcut uses Apple’s built-in actions and talks directly to GitHub. It does not upload your files or token to this public website.
